# HALO — Ideas & Backlog

## Product Mission
Transform folders from generic containers into meaningful,
understandable spaces.

---

## Positioning Shift — June 5, 2026

### Original Idea
HALO remembers projects.

Examples:
- SATURN
- NOVASEC
- MBA

Problem: This positions HALO primarily for engineers,
researchers, and project-based users. Too narrow.

### Updated Vision
HALO gives every folder an identity.

Examples:
- Taxes
- Downloads
- Vacation Photos
- Recipes
- Family Documents
- SATURN
- MBA

### Core Insight
Every folder contains context that users eventually forget.
HALO restores that context through:
- Visual identity
- Folder memory
- Folder relationships
- Smart summaries

### Target User
Anyone who uses folders.

### The Bigger Vision
HALO creates identity for digital spaces.
Today that's folders.
Later it could be:
- Projects
- Drives
- Archives
- Downloads
- Collections

Don't build any of that yet.
Ship folders first.

---

## Glow Concepts

### Option 4 — Memory Strength Glow
Folders glow based on how well HALO knows them.
- Weak glow → barely any memory
- Medium glow → understands contents
- Strong glow → knows project very well

### Option 5 — Workflow Trail Glow
HALO learns your navigation patterns.
Folders you usually open together glow softly.
Like breadcrumbs. No prompts. No chat.

## Future Feature Ideas

### Folder DNA
Every folder gets a visual fingerprint.
A combination of icons representing its themes.
Examples:
- SATURN → 🛰️ + 🔒 + 📡
- MBA → 🎓 + 💰 + 📄
- Taxes → 📄 + 💰 + 🗂️

### Session Restore
Reopen laptop and see where you were.
Fading footprints across the file system.
Instant context restoration.

### Semantic Search
Find files by memory, not filename.
"Satellite proposal from last winter"
App finds it without exact filename.

### Project Mood
Watch folder activity levels.
Show which projects are active vs abandoned.
Examples:
- NOVASEC → High activity this week
- SEAWAVE → No activity for 3 months

### AI Breadcrumbs
Open a folder after 8 months.
Instead of 47 files you see:
- Last worked here: November 2025
- Main topics: 5G, NTN, ESA
- Important files: Architecture_v7.pptx

### Folder Stories
Hover over a folder.
See a mini Wikipedia page.
- Created: 18 months ago
- Purpose: ESA Phase B proposal
- Contains: 12 presentations, 4 deliverables
- Keywords: NTN, Cybersecurity, Resilience

## Positioning Ideas
- "Give every folder an identity"
- "Your folders already store your work. HALO helps them tell their story."
- "Folders that know what they are"
- "Stop reopening old folders to remember what they contain"

## Target Markets
- Knowledge workers with large folder collections
- Engineers and researchers with complex projects
- Students with coursework and applications
- Freelancers with client folders
- Parents with family archives
- Anyone who has ever forgotten what a folder contains

## Risks
- Finder/Explorer hover integration is hard
- Accessibility permissions scare users
- Windows support adds complexity
- Feature creep kills solo projects
- Becoming too niche (project folders only)

---

## Rules for Building HALO
- Ship memory before glow
- Ship icons before relationships
- Never add a chat window
- Keep it local first always
- One version at a time
- Generic by design — works for any folder
- The empty state is always: No folders added yet
