# HALO — Ideas & Backlog

## The Core Idea
A memory layer for your files.
Folders remember what you forgot.

## Glow Concepts

### Option 4 — Memory Strength Glow
Folders glow based on how well HALO knows them.

- Weak glow → barely any memory
- Medium glow → understands contents
- Strong glow → knows project very well

### Option 5 — Workflow Trail Glow
HALO learns your navigation patterns.
Folders you usually open together glow softly.
Like breadcrumbs. No prompts. No chat.

## Future Feature Ideas

### Folder DNA
Every folder gets a visual fingerprint.
A combination of icons representing its themes.
Example:
- SATURN → 🛰️ + 🔒 + 📡
- MBA → 🎓 + 💰 + 📄

### Session Restore
Reopen laptop and see where you were.
Fading footprints across the file system.
Instant context restoration.

### Semantic Search
Find files by memory, not filename.
"Satellite proposal from last winter"
App finds it without exact filename.

### Project Mood
Watch folder activity levels.
Show which projects are active vs abandoned.
Example:
- NOVASEC → High activity this week
- SEAWAVE → No activity for 3 months

### AI Breadcrumbs
Open a folder after 8 months.
Instead of 47 files, you see:
- Last worked here: November 2025
- Main topics: 5G, NTN, ESA
- Important files: Architecture_v7.pptx

### Folder Stories
Hover over a folder.
See a mini Wikipedia page.
- Created: 18 months ago
- Purpose: ESA Phase B proposal
- Contains: 12 presentations, 4 deliverables
- Keywords: NTN, Cybersecurity, Resilience

## Pricing Ideas

## Risks
- Finder/Explorer hover integration is hard
- Accessibility permissions scare users
- Windows support adds complexity
- Feature creep kills solo projects

## Rules for Building HALO
- Ship memory before glow
- Ship icons before relationships
- Never add a chat window
- Keep it local first always
- One version at a time
