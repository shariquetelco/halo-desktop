What HALO does

Identity. Memory.
Relationships. Search.

Every folder you create tells a story. HALO helps you read it — without opening a single file.

🎨
Smart Identity
HALO automatically assigns icons, colors, and categories from the folder name. 250+ icons. 40 colors. 20 gradients. HALO suggests. You decide.
🧠
Folder Memory
Add a description, see file counts, track last activity. Open a folder after 8 months and instantly know what it contains and why it exists.
🔗
Relationships
HALO connects related folders automatically. SATURN links to NOVASEC. MBA links to Finance. Remove suggestions you don't need. Add your own.
🔍
Search Inside Files
Not just filenames. HALO indexes PDFs, Word docs, PowerPoints, spreadsheets, notes and code. Find knowledge, not files. Fully local.
⚡
Instant Results
Everything runs on your device. No cloud processing. No uploads. Search results appear in milliseconds from a local SQLite index.
🪟
Cross Platform
Built with Tauri for macOS first. Windows support is coming. One codebase. Two platforms. Same identity engine. Same local index.

Privacy first

Your computer.
Your data. Always.

HALO was built with one rule: nothing leaves your device.

🔒
No cloud processing
Every index, every search, every result runs locally on your machine. Your files never touch a server.
📡
No internet required
After installation, HALO works fully offline. No API calls. No telemetry. No analytics. No account required.
🗄️
Local index only
Your search index lives at
