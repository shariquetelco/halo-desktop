# HALO — Roadmap

## Version 0.1 — Foundation
> Goal: App opens. Nothing more.

- [ ] Tauri project created
- [ ] App window opens on Mac
- [ ] Basic UI shell visible

## Version 0.2 — Folder Selection
> Goal: User can select a folder to monitor.

- [ ] Folder picker works
- [ ] Selected folder path stored
- [ ] Folder name displayed in app

## Version 0.3 — Smart Visual Identity
> Goal: Folders get icons and colors automatically.

- [ ] Keyword matching engine built
- [ ] Icon assigned from folder name
- [ ] Color assigned from folder name
- [ ] User can override manually
- [ ] Icons stored locally in SQLite

## Version 0.4 — Folder Memory Engine
> Goal: Folders get a memory profile.

- [ ] App scans folder contents
- [ ] Generates folder summary
- [ ] Identifies important files
- [ ] Stores memory profile in SQLite
- [ ] Last activity tracked

## Version 0.5 — Memory Card UI
> Goal: User sees folder context without opening it.

- [ ] Memory card component built
- [ ] Shows icon, color, summary
- [ ] Shows last activity
- [ ] Shows important files
- [ ] Shows related folders

## Version 0.6 — Folder Relationships
> Goal: App connects related folders.

- [ ] Keyword similarity engine
- [ ] Related folders detected
- [ ] Relationships shown in memory card

## Version 1.0 — Public Launch
> Goal: Stable, sellable product.

- [ ] All MVP features complete
- [ ] App tested on clean Mac
- [ ] Pricing and license system
- [ ] Landing page live
- [ ] Product Hunt ready

## Future — Post Launch
- [ ] Halo Glow effects
- [ ] Workflow breadcrumbs
- [ ] Activity timeline

## Principles
- One version at a time
- Test before moving forward
- No feature creep
